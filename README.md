# Constraint-Checked State Records

Author: Lijie Wang, Independent Researcher  
Date: May 2026  
Contact: wanglijie100@gmail.com

Clean-room minimal artifact for a constraint-checked symbolic pipeline over
normalized records.

本仓库是一个 clean-room 的最小学术 artifact，用于归一化符号记录和约束检查后的聚合评分。

The pipeline is:

管线为：

```text
r_t -> s_t -> p_t -> z_t -> q
```

The implementation-level chain is:

实现层链条为：

```text
SyntheticCase -> TraceStore -> Baselines -> ConstraintCheck -> ScoreCard
```

These two views describe the same artifact at different levels. The symbolic
chain is the paper formulation; the implementation chain is the reproducible
module boundary.

这两种表述描述的是同一个 artifact 的不同层级：符号链条是论文中的形式化表达，实现层链条是可复现代码的模块边界。

## Contributions / 贡献

1. A minimal symbolic pipeline that separates state construction, candidate
   generation, constraint checking, and aggregate evaluation.  
   定义一个最小符号管线，分离状态构造、候选生成、约束检查和聚合评估。
2. A reproducible artifact with fixed synthetic cases, deterministic baseline
   methods, and finite explicit constraints.  
   提供一个可复现 artifact，包含固定 synthetic cases、确定性 baseline 方法和显式有限约束。
3. A pilot comparison showing score and pass-rate tradeoffs under the same
   checked-record protocol.  
   在同一 checked-record 协议下展示 score 和 pass-rate 的 tradeoff。

  pilot 聚合结果。
- `paper/outline.md`: minimal formulation.  
  最小形式化表达。
- `paper/outline.zh.md`: Chinese minimal formulation.  
  中文最小形式化表达。
- `paper/research_agenda.md`: working research agenda for the second paper.

## Reproduce / 复现

Install the single test dependency:

安装唯一测试依赖：

```text
python -m pip install -r requirements.txt
```

Run the pilot and checks:

运行 pilot 和检查：

```text
python -m scripts.run_pilot --cases data/cases_small.jsonl --runs 10 --methods summary_loop,template_grid,symbolic_rule --out outputs/pilot_runs.jsonl
python -m scripts.export_summary --input outputs/pilot_runs.jsonl --out outputs/summary_agg.csv
python -m pytest -q
python -m scripts.term_scan
```

## Limitations / 局限

The artifact uses synthetic records, deterministic baselines, and finite
constraint lists. The reported metrics describe only this closed protocol and
should be read as baseline measurements, not broad empirical claims.

本 artifact 使用 synthetic records、确定性 baselines 和有限约束列表。报告的指标只描述这个闭合协议，
应理解为基线测量，而不是广泛经验结论。

## Release Boundary / 发布边界

The public release boundary is the normalized case bank, deterministic pipeline
code, aggregate CSV, tests, term scan, README, license, and paper notes in this
repository. Generated checked records can be regenerated from the included
commands and are not required as hand-authored source material.

公开发布边界包括：归一化 case bank、确定性管线代码、聚合 CSV、测试、term scan、README、许可证和
paper notes。生成的 checked records 可以通过仓库命令重新生成，不需要作为手写源材料维护。

## Boundary Closure / 边界收束

In this repository, "closure" means artifact boundary closure, not mathematical
convergence. The public review object is closed around four finite interfaces:

1. fixed synthetic normalized records;
2. deterministic state and proposal construction;
3. finite explicit constraint checks; and
4. aggregate scores and constraint-failure summaries.

本仓库中的“收束”指 artifact boundary closure，不是数学意义上的 convergence。
当前公开评审对象收束在四个有限接口内：

1. 固定的 synthetic normalized records；
2. 确定性的状态构造和候选生成；
3. 有限显式约束检查；
4. 聚合评分和约束失败摘要。
