\begin{abstract}
This paper describes a compact computational artifact for comparing linear
symbolic methods over normalized records. The artifact maps synthetic cases to
trace stores, applies deterministic baseline methods, checks candidate records
against finite constraint sets, and reports aggregate scores. The implementation
is designed for direct reproduction with a small fixed case bank and a concise
pilot protocol.
\end{abstract}

\section{Introduction}
Symbolic pipelines are often easiest to evaluate when each transformation is
kept explicit. This work studies a minimal setting in which normalized records
are converted into intermediate states, method-specific candidates, checked
records, and aggregate score cards.

The contribution is an inspectable artifact with twenty synthetic cases, three
deterministic baseline methods, a constraint checker, and a CSV score summary.

\section{Methodology}
The artifact follows a linear sequence:
SyntheticCase, TraceStore, Baselines, ConstraintCheck, and ScoreCard. Each stage
accepts structured records and returns structured records. The baseline methods
share the same input representation and differ only in candidate selection.

\subsection{Baseline Methods}
\textbf{summary\_loop} selects the strongest accumulated state.
\textbf{template\_grid} selects a state by trace position and pass index.
\textbf{symbolic\_rule} selects from states that satisfy the case lists when
available.

\section{Experimental Protocol}
The pilot contains twenty synthetic cases, three methods, and ten repeated
passes. This gives 600 checked records. The aggregate table reports average
score, pass rate, and average record count for each method.

\section{Conclusion}
The artifact provides a small reproducible basis for studying linear symbolic
state construction and constraint checking. The pilot establishes a compact
baseline for comparing candidate selection strategies under the same normalized
record inputs and finite case lists.
